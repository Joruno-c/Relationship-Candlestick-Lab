# 我们的课程项目群：公开数值回归样本

本目录来自 2026 年 11 月 18 日保存的真实群聊分析快照，覆盖 **1497 条记录、5 位成员**。时间范围为 2026-09-10 15:03:47 至 2026-11-18 00:01:04（UTC+08:00）。记录包含 1276 条文字/引用回复、200 条媒体/动作和 21 条系统通知。

为了适合公开仓库，成员被替换为 `Member 01` 至 `Member 05`；所有正文、引用内容、附件元数据和评分理由均被替换为固定占位文本，原始标签被替换为记录类型。维度仅保留预定义的协作类别。姓名映射、原始聊天文件、学号、账号、密钥和附件没有包含在内。实际时间戳和数值轨迹仍然保留。

这是一份**已有评分的数值回归样本**：保留原记录顺序、时间和两项相对评分，可重现逐条指数和全部 11 种周期的 OHLC。它不是可读的原始群聊，也不用于重新评估 AI 对原文的语义判断。由于正文长度与标签被替换，互动量和事件标签统计不等于原始结果。

| 文件 | 用途 |
| --- | --- |
| `messages.csv` / `messages.jsonl` | 同一组占位聊天的两种输入格式 |
| `scored.jsonl` | 含时间、匿名发送者和已有评分的自包含文件，可直接导入网页 |
| `expected_index.csv` | 从原保存结果提取的每条指数，作为独立回归基准 |
| `expected_ohlc.json` | 原保存结果的全部 OHLC 与消息数，不包含事件原文 |
| `manifest.json` | 数量、时间、预期值、隐私处理及公开文件 SHA-256 |

在仓库根目录运行：

```bash
python scripts/run_group_demo.py
python -m pytest tests/test_group_chat.py tests/test_group_demo_api.py -q
```

脚本无需 API Key，不会重新调用模型。它生成 `output/group_demo/relationship_chart.html` 和 11 种周期 CSV，保存可在服务重启后恢复的网页任务，并打印任务地址。网页也可以直接选择首页的群聊演示，或导入 `examples/group_chat/scored.jsonl`。
